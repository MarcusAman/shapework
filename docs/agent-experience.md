# shapework. Agent Experience Specification

## Principles
Real estate agents are constantly on the move and resist adopting complex, secondary compliance platforms. Therefore, shapework. operates under a strict directive: **Brokerage operations need structure; agents need simplicity.**

Agents are not required to log into a heavy, desktop application. Instead, they interact with shapework. via channels they are already comfortable with: SMS, email, and secure mobile micro-links.

---

## Interactive touchpoints

### 1. Structured Emails and SMS
When an action is required (e.g., an HOA disclosure is missing, or an appraisal needs scheduling), shapework. generates a clean, concise, property-linked request sent via standard SMS or email.

### 2. Secure Mobile Micro-links
Clicking a link inside an SMS takes the agent to a lightweight, responsive page requiring no password login. The page is single-purpose and highly optimized for mobile devices:
* **Clear Task Context**: e.g., "Seller disclosure needed - 1243 Oak Ridge Lane. Due by tomorrow, 2:00 PM."
* **Immediate Actions**:
  * **Upload Document** (triggers standard phone camera or files browser).
  * **Mark Completed** (e.g., "I have sent this to escrow").
  * **Request Assistance** (ping the compliance coordinator).
  * **Add Note** (quick text input).

### 3. Micro-Composers & Forms
Forms contain simple, large touch targets (at least 44px) and support swift interaction, ensuring agents can update the operations team in under ten seconds.
