# shapework. MVP Product Roadmap

This document maps out the immediate product priorities for transitioning shapework. from a demo prototype to a production platform.

---

## MVP 1 — Request Desk
- **Goal**: Give agent requests one front door.
- **Scope**:
  - Email/SMS/manual/secure link intake
  - Classification (marketing, listings, sign install)
  - Missing-info detection (property, dates, assets)
  - Routing to correct staff coordinators
  - Clarification email/SMS drafts
  - Audit logs of all incoming loops

---

## MVP 2 — Owner Shield
- **Goal**: Protect owner time and prevent routine operational escalations.
- **Scope**:
  - Escalation rules definition (legal, splits, partnerships)
  - Routing decisions log
  - Owner decision queue for Alex Carter
  - Interruption reporting dashboard (avoided blocks count)
  - Audit trail logging

---

## MVP 3 — Deal Intake Guard
- **Goal**: Catch missing contract forms and missing transaction files when deals become active.
- **Scope**:
  - Deal signal detection (MLS status changes, emails)
  - Required intake checklist (agreements, file, coordinator, dates)
  - Missing form detection (prompting agents)
  - Coordinator assignment staging
  - Agent clarification email drafts
  - Audit trails of matched deals

---

## MVP 4 — Closing Compliance Guard
- **Goal**: Catch missing compliance items before closing week.
- **Scope**:
  - Closing date tracking (T-30, T-14, T-7 sweeps)
  - Required document checklist sweeps
  - Secure upload link drafts
  - Compliance review coordinator assignment
  - Escalation rules for late files
  - Audit log updates

---

## Later
- **Listing Launch Board**: Checklist boards for marketing launch events
- **Agent Onboarding Board**: Milestones and bio copywriting
- **Sign Inventory**: Ledger tracking yard signs and lockboxes
- **Review Request Trigger**: Google review prompts staged on deal close
- **Full Production Integrations**: Real RESO MLS feed API, QuickBooks API, SkySlope API, and Twilio SMS Gateway connections
