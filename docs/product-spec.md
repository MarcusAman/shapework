# Product Specification: .Shapework

## Overview
.Shapework is the AI Operations Employee for Real Estate Brokerages. It connects to the brokerage’s existing systems, observes operational activity, detects friction and risk, recommends actions, prepares finished work, and executes repeatable administrative tasks.

## MVP Objectives
1. Daily Brokerage Briefing
2. Transaction Risk Monitor
3. Listing Launch Coordinator
4. Follow-Up and Action Coordinator

## Primary User Roles
- Brokerage Owner / Executive
- Brokerage Administrator
- Operations Manager
- Transaction Coordinator
- Real Estate Agent
- Read-Only Leadership User
- External Participant

## Key Features
- Command Center
- AI Operator
- Transactions (List/Kanban)
- Listings Launch Workflow
- Workflow Library
- Integration Center
- Analytics & ROI Tracking

## Tech Stack
- Next.js (App Router paradigm on Express + Vite)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase (PostgreSQL, Auth, Storage, Realtime)
- Gemini API (AI Logic)
- Zod (Validation)
