# Support Boundaries & Intellectual Property Agreement

This document outlines the support boundaries, account ownership, and intellectual property terms for the **shapework.** pilot.

---

## 1. Operating Layer Support Scope
* **Supported**: shapework. supports the custom workspace dashboards, routing logic, Work Queue rules, and Approval Center safeguards configured for your brokerage.
* **Third-Party Exclusions**: Platform outages or service changes in connected third-party tools (e.g. Rechat, Dotloop, Gmail, Outlook, API Nation, Zapier) remain the sole responsibility of their respective providers.

## 2. Maintenance & Custom SOW Boundaries
* **Retainer Services**: The monthly software retainer covers standard hosting, security patches, and triage support for the operational layout.
* **New Features**: Major layout updates, new workflow templates, custom database adjustments, or new software integrations require a separate Statement of Work (SOW) and are not included in standard retainer support.

## 3. Account Ownership & Access Credentials
* **Client Credentials**: The brokerage client owns and maintains all logins, billing profiles, and API access keys for their external platforms.
* **Security Controls**: shapework. coordinators will never ask for or store master account passwords. All integrations should be linked via secure OAuth channels.

## 4. Intellectual Property & Handoff Process
* **Core IP**: shapework. retains ownership of all reusable code modules, workflow templates, intelligence routing heuristics, and background libraries.
* **Brokerage Data**: The client owns all raw client names, transaction prices, and coordinator comments stored in their workspace.
* **Handoff Plan**: If the engagement is terminated, shapework. will export all active transaction databases and audit ledger history in CSV format within 5 business days. Access to the shapework. Command Center panels will expire at the end of the current billing cycle.
